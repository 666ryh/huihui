# 辉辉客服工作台

工作台面向人工客服，核心任务是找到需要回应的用户、查看上下文并回复。

色彩：主紫 #70508f、深紫 #593d74、背景 #f5f2f8、白色 #ffffff、正文 #332c3d、辅助文字 #766d80。系统中文无衬线字体，主标题 25px，消息 14px，辅助信息 11–13px。主色用于选中、发送与客服身份，不用于大面积装饰。

桌面：页头品牌与账号；左侧邮箱搜索、接待中/已结束会话；右侧独立滚动消息区与固定输入区。移动端：会话列表进入详情，详情页提供返回按钮，输入区留出安全区域。布局以对话为中心，不加入无关统计卡片。

同账号按会话保留未提交草稿，切账号清空；失败请求保留内容与 requestId，只能重试相同消息。轮询每两秒在页面可见时执行，列表与消息错误保留现有数据。读取游标独立于发送返回的消息 ID，避免跳过并发用户消息。渲染完成且页面仍可见时才确认已读。
